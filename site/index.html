Kitsune

A lean Android gaming emulator for Windows. No ads, no telemetry, no bloat. Just the fastest open emulator core there is, set up for games.

Google's emulator core

The Android Emulator from AOSP, the one Android Studio ships. Apache-2.0, auditable, maintained by Google.

Hardware acceleration

Picks AEHD (Google's kernel driver, direct VT-x) or WHPX for you. Host OpenGL and Vulkan on your real GPU, pinned to the discrete card on laptops.

ARM games run

Google Play x86_64 images include libndk_translation, so arm64-only games work.

Keymapper that doesn't lag

Keyboard and mouse become multitouch through the emulator's gRPC control stream, straight into the virtual touchscreen. Joystick, autofire, swipes, pinch, mouse-look.

Nothing phones home

Metrics off, crash reporting off, no account, no launcher ads. It talks to dl.google.com only when you click install.

Play Store built in

Android 15 Google Play image by default; other versions one click away.

Requirements

  • Windows 10 2004 or Windows 11, 64-bit, with VT-x or AMD-V enabled in the firmware.
  • About 3 GB of disk for the emulator and one Android image, 8 GB of RAM or more.
  • For the fastest path (AEHD): Hyper-V, Virtual Machine Platform, WSL2 and memory integrity off. If you need those, Kitsune uses WHPX instead.

First run

  1. Unzip, run Kitsune.exe.
  2. Click Install / update components. It downloads the emulator, adb and the Android 15 Play image (about 2.1 GB) from Google and verifies every checksum.
  3. Click Install AEHD driver and accept the one UAC prompt (skip on Hyper-V machines).
  4. New to create an instance, then Launch. First boot takes under a minute; after that it resumes in seconds.
  5. Pick a keymap profile and press Edit on screen to drag the key badges onto your game's buttons.
Windows SmartScreen may warn about an unsigned download the first time. Click "More info", then "Run anyway". The zip's SHA-256 above lets you check what you got.

What it will not do

Root on Play imagesGoogle does not allow it. Pick a "Google APIs" image if you need root; it has no Play Store.
Hide from anti-emulator checksGames that refuse emulators will refuse this one.
More than 6 CPU coresThe emulator caps vCPUs at 6.
